## 2. Spike 结果

| Spike | 验证内容 | 结果 |
|---|---|---|
| A 截屏/裁剪 | xcap 1920×1080 抓屏；125% 下框选 400×240 CSS → 裁剪 500×300 物理像素，内容与选区一致 | ✅ |
| B 挂件 | 透明无边框、无白框；右上角穿透（WS_EX_TRANSPARENT=true），中心可点击（false）；拖动位移与鼠标一致（-237,-257）；原生右键菜单可用 | ✅ |
| C 遮罩 | 全屏 1920×1080 overlay；任务栏被暗化覆盖（像素亮度 127→73）；框选、确认、裁剪、预览正常 | ✅ |
| D 气泡 | 透明置顶，出现在挂件左侧；不抢焦点（前台仍是 Edge）；鼠标可穿透 | ✅ |
| E 热键/全屏 | `Alt+Q` 全局唤起；全屏无边框窗口时挂件与气泡隐藏，退出后挂件恢复 | ✅ |

其他实测：

- 冷启动后常驻内存约 33MB（仅挂件，无额外窗口）。
- 首次 `cargo` 编译约 1 分 44 秒；后续增量约 19 秒。
- 热键到遮罩可见约 1.24 秒（包含测试脚本 SendKeys 注入），后续可优化。
- 挂件在截屏前被隐藏，抓取的 PNG 中不含挂件自身。
- 设置窗口可打开；菜单“设置”/“退出”路径正常。

## 3. 已修复的问题

1. **框选松手丢最后一帧**：`pointerup` 未更新终点坐标，导致选区宽度少一截；已改为在 `pointerup` 时同步更新坐标。
2. **overlay 关闭生命周期**：新增 `closing_overlays` 标志；overlay 被 Alt+F4 关闭时自动取消会话，避免 `session_active` 卡住。
3. **调试代码清理**：移除临时气泡热键、调试日志与未使用函数。

## 4. 待办 / M1 风险

- 挂件位置持久化、贴边吸附尚未实现（M1）。
- 托盘图标左键/右键菜单只做了代码路径，未做精确定位测试（M1 补）。
- 多显示器 + 混合 DPI 无硬件可测；当前按 xcap 显示器索引映射，后续改为按物理几何匹配。
- 气泡尾巴方向目前固定在左下，位于挂件左侧时应朝右；M1 调整。
- 遮罩冷启动约 1.2s，后续考虑预创建 overlay、减少抓屏编码耗时。
- 设置页目前是 M0 调试面板，M3/M5 替换为正式设置。

## 5. Go / No-Go

五项核心能力全部通过，未发现阻塞性问题。**Go**：继续 M1（挂件完整交互、位置持久化、托盘与全屏细节）。
